# 검토 메모: 형사사법비용 변동 원인과 관세청·해양경찰 비용 유입 경위 (2026-11-05)

대상: 「마약류 범죄의 형사사법 비용」 원고 최신판(2024년 기준, 10.29_1, 14쪽), 저장소 구조-v1.2(2026. 11. 2.), 중간보고 PPT·예상 질문·답변지·발표 스크립트(2026. 11. 4.).

## 1. 요약

- 형사사법비 합계: 중간보고 2,699.1억 원 → 최신 원고 3,507.9억 원(+808.8억 원, +30.0%). 보호관찰 제외 시 2,596.8억 원 → 3,410.9억 원.
- 변동 원인은 2개 기관뿐임.
  - 교도소 +814.1억 원: 분자·분모를 1일 평균(3,477 ÷ 61,366명)에서 12월 말 현원(6,629 ÷ 62,961명)으로 바꿈.
  - 보호관찰소 −5.3억 원: 접수건수(2,579 ÷ 48,765건)에서 12월 31일 기준 접수인원(2,089 ÷ 41,643명)으로 바꿈.
  - 경찰·검찰·법원·국립법무병원은 값이 같음.
- 관세청·해양경찰 비용은 원래 계획에도, 원고에도 없음. 비용구조도의 '구현 모델'(2-1)에서 "수정 · 기관 확대"로 들어간 뒤 검토메모, 구조 시트, 원고 한계 문장, 중간보고 자료로 옮겨 감. 연구진 합의 없이 범위가 넓어진 것임.

## 6. 결정할 것

1. 교도소 마약류 인원: 1일 평균(정의 확인 후 수용자 기준으로 재산출) 또는 12월 말 현원 중 하나. 정한 기준을 구금 기간 생산성 손실에도 똑같이 씀.
2. 보호관찰: 접수건수 또는 접수인원.
3. 관세청·해경: 범위에서 제외(원래 계획). 한계 문장을 남길지 여부.
4. 원고 결론 본문과 <표 18>의 1인 비용 합계 처리.
